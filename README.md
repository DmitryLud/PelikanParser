# Локальный парсер цен по Eurocode

Проект входит в личный кабинет, по очереди ищет Eurocode из Excel и сохраняет минимальную найденную цену вместе с производителем. Если карточки найдены, но ни в одной нет цены, результат получает статус `Нет в наличии`.

Проект не содержит адрес сайта, логин или пароль. Эти данные задаются после скачивания в локальных файлах `config.yaml` и `.env`.

## Быстрый запуск в Windows

1. Установите Python 3.11 или новее.
2. Запустите `setup.bat`. Скрипт создаст виртуальное окружение, установит зависимости и браузер Chromium.
3. Откройте `.env` и заполните:

   ```dotenv
   PELIKAN_EMAIL=ваша-почта
   PELIKAN_PASSWORD=ваш-пароль
   ```

4. Откройте `config.yaml` и замените `site.login_url`. Если после входа каталог не открывается автоматически, заполните `site.catalog_url`.
5. Внесите Eurocode в столбец `Eurocode` файла `input/eurocodes.xlsx`.
6. Для проверки настроек выполните:

   ```powershell
   .venv\Scripts\python -m pelikan_parser check --config config.yaml --env .env
   ```

7. Запустите `run.bat`. Результат появится в `output/results.xlsx`.

Для первого запуска браузер видимый. После настройки можно задать `browser.headless: true`.

Столбец `Eurocode` в шаблоне имеет текстовый формат. Сохраняйте его таким, если код может начинаться с нуля.

## Формат результата

Первые четыре столбца:

- `Eurocode` — исходный код;
- `Цена` — минимальная числовая цена среди найденных карточек;
- `Производитель` — производитель именно той карточки, где выбрана минимальная цена;
- `Статус` — `В наличии`, `Нет в наличии` или `Ошибка`.

По умолчанию добавляются диагностические столбцы: количество карточек, количество карточек с ценой и комментарий. Их можно отключить через `output.include_diagnostics: false`.

## Настройка элементов сайта

Для карточек результата используются точные локаторы по присланному HTML: одна позиция определяется как `li > article`, производитель — по подписи `Производитель:`, а цена — по отдельному элементу со знаком `₽`. Длинные Tailwind-классы намеренно не используются, потому что они могут меняться. Для входа и поля поиска пока остается список резервных локаторов; программа берет первый найденный вариант.

Обычно достаточно уточнить следующие поля:

| Поле | Что должно находить |
| --- | --- |
| `selectors.login.email` | поле электронной почты |
| `selectors.login.password` | поле пароля |
| `selectors.login.submit` | кнопку «Вход» |
| `selectors.catalog.search_input` | поле «Наименование / еврокод / OEM номер» |
| `selectors.catalog.search_submit` | кнопку «Поиск» |
| `selectors.results.item` | одну целую карточку результата |
| `selectors.results.manufacturer` | производителя внутри карточки |
| `selectors.results.price` | цену внутри карточки |
| `selectors.results.expand` | кнопку раскрытия карточки, если цена скрыта |

Поддерживаются CSS, XPath и локаторы по видимому тексту:

```yaml
selectors:
  results:
    item:
      - "css=.catalog-card"
    price:
      - "css=.catalog-card__price"
      - "xpath=.//*[contains(@class, 'price')]"
    expand:
      - "text=Раскрыть расширенное описание"
```

Чтобы получить CSS-селектор в Chrome/Chromium: откройте страницу, нажмите `F12`, выберите стрелкой нужный элемент, щелкните его HTML правой кнопкой и выберите `Copy` → `Copy selector`. Для `results.item` выбирайте внешний контейнер одной карточки, а не весь список.

Если на сайте цена указана без `руб.`, `RUB`, `BYN`, `Br` или `₽`, измените `patterns.price`. В шаблоне должна быть группа `(?P<price>...)`, содержащая только число цены. Например:

```yaml
patterns:
  price: "(?i)Цена\\s*:\\s*(?P<price>\\d+(?:[ \\u00A0]\\d{3})*(?:[.,]\\d{1,2})?)"
```

## Диагностика

Если вход или обработка отдельного Eurocode завершаются ошибкой, программа сохраняет снимок страницы и HTML в папку `debug`. По этим файлам можно точно подобрать селекторы, не передавая пароль.

Полезный тест одного кода:

```powershell
.venv\Scripts\python -m pelikan_parser run --config config.yaml --env .env --limit 1 --headful
```

Если сайт использует CAPTCHA или одноразовый код, оставьте браузер видимым и задайте `browser.manual_login_timeout_seconds: 120`. Программа даст время завершить вход вручную.

## Командная строка

```powershell
# Создать локальные config.yaml и .env из примеров
.venv\Scripts\python -m pelikan_parser init

# Проверить конфигурацию и входной Excel без открытия сайта
.venv\Scripts\python -m pelikan_parser check

# Полный запуск
.venv\Scripts\python -m pelikan_parser run
```

Используйте автоматизацию только для учетной записи и сайта, к которым у вас есть разрешенный доступ. Интервал между запросами регулируется через `browser.delay_between_codes_ms`.
